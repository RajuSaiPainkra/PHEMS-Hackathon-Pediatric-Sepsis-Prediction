# PHEMS-Hackathon-Pediatric-Sepsis-Prediction

### Project Objective

The primary objective of this challenge is to develop a machine learning algorithm capable of early detection of sepsis in pediatric patients using retrospective physiological data. The goal is to predict sepsis at least 6 hours before the clinical prediction, leveraging time-series data collected in the Pediatric Intensive Care Unit (PICU). Early detection can significantly improve patient outcomes, reduce mortality rates, and alleviate the economic burden on healthcare systems.
